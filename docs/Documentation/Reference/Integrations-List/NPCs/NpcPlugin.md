# [NpcPlugin](https://www.spigotmc.org/resources/87761/)

@snippet:versions:minimum@ _3.6.0_

If you have this plugin you can use its NPCs.
It is a player-like, packet based plugin with an in-game NPC editor, click actions and a built-in path system.

!!! warning "Paper flavour only"
    BetonQuest integrates with the Paper flavour of the plugin, which is named `NpcPlugin-Paper`.
    The Spigot flavour is a separate plugin and does not provide this integration.

!!! info
    NpcPlugin integration supports all [BetonQuest NPC](index.md) features.
